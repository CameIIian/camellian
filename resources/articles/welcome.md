# はじめての記事

`resources/articles` に置いた Markdown を、このページでそのまま読めるようにしました。

## できること

- 見出し (`#`, `##` ...)
- リスト (`- item`)
- 引用 (`> quote`)
- コードブロック
- [外部リンク](https://www.typescriptlang.org/)

> ターミナルっぽい見た目と Dracula カラーで表示されます。

---

### サンプルコード

```ts
const theme = "dracula";
console.log(`Markdown article theme: ${theme}`);
```
