# もしもう一度Windowsと向き合うなら
Tag: Windows
date: 2026/01/22

### 1. まずやること
セキュリティソフト: uninstall
エクスプローラ: 右クリックをwin10化
クリップボードの履歴: ON
OneDriveのバックアップ領域を制限する
### 2. インストールするもの
#### 普段
- PowerToys
	Win向け便利機能詰め合わせ
- Discord
- Brave, Vivaldi, Edge等
	Chromeより便利だったり、軽かったりするブラウザを選ぼう
- BlueStacks
	Androidエミュ、対策されてなければ快適に遊べる
- Steam
	ゲーム遊ぶ用

#### ファイル系
- Tablacus Explorer
	便利なファイラ
- TresGrep
	ファイル検索ソフト、word等の中に書いてあることまで探してくれる
- TeraCopy
	コピー用ツール、標準より便利？
- LocalSend
	LAN内でデータを楽にやり取りするのに便利？
- 7zip
	圧縮回答ソフト、便利で早い
- irfan view
	老舗の軽量ビューワ
- ffmpeg
	画像変換等、怪しいサイト使わないでね
- yt-dlp
	youtube等からダウンロードするソフト
	Pythonが必要かも知れない

#### 編集
- Obsidian, Keep等
	軽いメモ用、どこからでも見返せるのがいい
- VSCode
	エディタなら一択じゃない？
- Antigravity, cursor
	AIエディタガッツリ使いたいなら
- Visutal Stadio
	たまに依存関係として求められる、その時に入れる
- Aviutil2
	楽にインストールできて普通に使える動画編集アプリ
	でもなぜか貴重
- Reaper, Audacity
	音声編集、尖った編集したくなったとき用

#### ハードウェア系
- Nvidia Driver系
	無いとパフォーマンスでないからな
- MultiMonitorTool
	モニター管理、プロファイル保存

	マウス操作をカスタマイズするソフト
